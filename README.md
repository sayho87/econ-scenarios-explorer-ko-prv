# Econ Scenario Explorer — 한국어 해설 (비공개)

Anthropic [Econ Scenario Explorer](https://www.anthropic.com/institute/econ-scenarios) 페이지의 한국어 해설·요약 문서입니다.

## 내용
- 과업(task) 기반 경제 모델 설명
- 세 가지 시나리오: 점진적 변화(lv1) · 상당한 변화(lv2) · 극단적 변화(lv3) (원문 표기 Modest / Substantial / Extreme)
- 1만 명 설문 결과
- 발견 1~4 (GDP / 직업 재배치 / 임금 / 노동·자본 몫)
- 모델 한계

## 안내
- **원문 복제·번역이 아닌 해설·요약 문서**입니다 (인터랙티브·이미지 미포함)
- 수치·그래프의 정확한 근거는 [원문](https://www.anthropic.com/institute/econ-scenarios)과 [기술 보고서 PDF](https://www-cdn.anthropic.com/files/4zrzovbb/website/cf58f84d46a4a76bf5a5b039ac695fba6b80041c.pdf)에서 확인
- 원문 저작권은 Anthropic 소유
